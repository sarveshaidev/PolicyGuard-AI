# PolicyGuardAI Dummy Talent Pool

This folder contains synthetic resumes generated for PolicyGuardAI development/testing.

- 25 separate PDF resumes
- Synthetic names and professional profiles
- No real personal data
- Intended for Talent Intelligence / JD matching demonstrations

Suggested workflow:
1. Upload these PDFs into the Talent Intelligence / Bench Pool area.
2. Create or upload a Job Description.
3. Run Match Talent.
4. Inspect ranked candidates, matched skills, and explanations.

Do not use these synthetic profiles for real hiring decisions.
